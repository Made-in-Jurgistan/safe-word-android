# Security Policy

## Supported versions

Security fixes are currently provided for the latest `main` branch only. This
repository is an evaluation release and does not promise security support for
released APKs or forks.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately by
emailing `madeinjurgistan@gmail.com` with:

- a concise description and affected component;
- reproduction steps or a minimal proof of concept;
- the affected commit, version, or build;
- the impact you believe an attacker could achieve.

Please avoid including personal data, credentials, or private audio/transcripts
in the report. If supporting files are required, describe them first and wait
for a private upload channel.

You can expect an acknowledgement within 14 days. The maintainer will assess
the report, coordinate a fix where appropriate, and credit the reporter unless
they request anonymity.

## Scope

The Android application, repository source, build configuration, and bundled
assets are in scope. Social engineering, unsupported modified APKs, and issues
in third-party services are out of scope.
